# Search Growth OS

> Google Search & AI Search growth system for SEO, AEO, GEO, agentic search and measurable growth.

Search Growth OS is an independent, evidence-driven operating system for improving discoverability, visibility, citation, task completion and conversion across Google Search and AI-assisted search experiences.

**Current focus:** Google Search, Google AI search experiences, Search Console, GA4, crawlability, AI visibility measurement and agentic task completion.

> This is an independent open-source project and is not affiliated with or endorsed by Google.

## Growth model

`Technical Access → Search Visibility → AI Visibility → Agentic Completion → Conversion / Revenue`

## Core agents

| Agent | Responsibility |
| --- | --- |
| AEO Foundations | Technical access, crawling, rendering, indexing boundaries and platform access |
| SEO Specialist | Organic demand, intent, search visibility, content architecture and conversion |
| GEO Strategist | AI mentions, recommendations, citations, source visibility and AI referrals |
| Agentic Search Optimizer | Agent task discoverability, execution, post-conditions, safety and completion |
| Search Growth Orchestrator | Routing, evidence normalization, prioritization and cross-channel roadmap |

## Engineering principles

- Evidence before claims: `VERIFIED / PROVIDED / OBSERVED / INFERRED / HYPOTHESIS / UNKNOWN`
- No fabricated benchmarks, guaranteed uplift or fake precision
- Platform facts are time-sensitive and must be re-verified before operational recommendations
- SEO, AEO, GEO and agentic metrics remain distinct even when they feed one business backlog
- Deterministic validation before optional model-based evaluation
- No secrets or client PII in Git

**Phase 1 — Engineering foundation:** migrating the reviewed Search Growth methodology, registry, schemas, eval infrastructure, CLI, regression guardrails and CI into this standalone repository.

**Phase 2 — Tool adapters:** Google Search Console, GA4, crawler/robots/sitemap checks, log ingestion and AI visibility providers.

**Phase 3 — Delivery:** full audits, prioritized roadmaps, client workspaces and recurring reports.
